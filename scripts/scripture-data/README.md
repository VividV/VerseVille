# Scripture data build & verification

`src/data/scriptures.json` and `src/data/topics.json` are generated by `build.py` from the verse list,
topics and explanations in `verses.py`. **Edit `verses.py`, not the JSON.**

The verse text is never typed by hand. `build.py` takes the wording from one public-domain KJV source and
checks it word-for-word (ignoring case and punctuation) against a second, independent KJV source. Any
disagreement is printed as `MISMATCH` for a person to look at.

Known, expected differences (already reviewed):

- Psalm 23:1, 46:1, 119:105: source B includes the Psalm heading ("A Psalm of David." etc.) in verse 1. We use the verse without the heading.
- Acts 1:8: source A spells "Judæa", source B "Judea". We keep the traditional "Judæa".

## Re-running

```bash
mkdir -p /tmp/kjv/kjv-a /tmp/kjv/kjv-b
curl -o /tmp/kjv/kjv-a/kjv.json https://raw.githubusercontent.com/thiagobodruk/bible/master/json/en_kjv.json
curl -o /tmp/kjv/kjv-b/kjv.json https://raw.githubusercontent.com/scrollmapper/bible_databases/master/formats/json/KJV.json
python3 scripts/scripture-data/build.py /tmp/kjv src/data
npm test   # data checks in src/data/scriptures.test.ts
```

Explanations were written for VerseVille in plain, non-denominational language and should be reviewed by
a trusted reader (pastor, Bible-study leader) before public release.
